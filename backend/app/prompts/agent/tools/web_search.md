## web_search 최종 답변 규칙

`web_search`는 참고용 로그를 남기기 위한 도구가 아니라, 사용자의 질문에 답하기 위한 외부 근거 수집 도구다.

- 이 도구를 실행했으면 검색 결과를 반드시 읽고, 질문에 직접 답하는 내용을 `answer_markdown`에 합성한다.
- 로컬 자료가 없거나 부족해도 웹 검색 결과가 질문에 답할 수 있으면 답변을 생성한다. `no_evidence` 또는 로컬 자료만을 근거로 한 답변으로 끝내지 않는다.
- 검색 결과를 단순히 "검색했다"고 알리는 데 그치지 말고, 핵심 사실·추세·비교·불확실성을 사용자의 언어로 요약한다.
- 웹 검색 결과를 사용한 답변에는 실제로 사용한 출처마다 `web_citations` 항목을 포함한다. 답변 본문에는 해당 출처를 `[W1]`, `[W2]` 형식으로 표시한다.
- `[W#]`는 현재 실행에서 OpenAI가 반환한 출처에 대응할 때만 사용한다. URL을 임의로 만들거나, 반환되지 않은 출처를 추측하거나, `cite...` 같은 내부 citation 마크업을 출력하지 않는다.
- 검색 결과가 서로 충돌하거나 신뢰도가 낮으면 이를 명시하고, 확인 가능한 사실과 해석을 구분한다.
- 최종 JSON의 `web_citations[].citation_key`는 본문에 사용한 `[W#]`와 일치해야 하며, `url`·`title`·`publisher`는 검색 결과의 메타데이터를 그대로 사용한다.
- 웹검색과 로컬 자료를 함께 사용하면 두 근거를 구분해 통합하되, 로컬 근거는 `[S#]`, 웹 근거는 `[W#]`로 표시한다.

사용자에게 웹 정보를 표시할 때 출처 링크는 눈에 띄고 클릭 가능해야 한다. 백엔드는 반환된 URL을 저장하고 프론트엔드는 답변의 `[W#]`와 연결된 출처 카드로 표시한다.
