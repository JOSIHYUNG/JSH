# Agent 도구 정책

- 현재 질문과 최근 대화 3개를 기준으로 필요한 도구만 선택한다. 한 번의 cycle에는 도구 호출을 최대 하나만 실행한다.
- 로컬 지식이 질문의 핵심 근거가 될 수 있으면 먼저 `search_knowledge`를 사용한다. 결과는 최대 3개 청크이며, 반환된 청크와 연결 개념만 근거로 사용한다.
- 개념 관계나 원문 주변 문맥이 꼭 필요할 때만 `explore_node`를 사용한다. 여러 노드를 무작정 탐색하지 말고 필요한 노드만 선택한다.
- 최신성·외부 정보·로컬 자료에 없는 사실이 필요하면 `web_search`를 사용한다. 웹검색을 실행했다면 검색 결과를 최종 답변에 반드시 반영하고, 웹 출처를 `W1` 이상으로 저장·표시한다.
- 도구 오류가 발생하면 오류 코드·원인·재시도 가능 여부를 확인하고, 오류 메시지의 제안에 따라 입력을 좁히거나 다른 도구를 선택한다. 같은 잘못된 호출을 반복하지 않는다.
- 최종 JSON은 answer-contract를 준수한다. 본문 출처 표기는 `[S#]` 또는 `[W#]`만 사용하며 OpenAI 내부 citation 마크업은 사용하지 않는다.
- 웹검색을 사용한 뒤 `web_citations`가 비어 있거나 본문에 `[W#]`가 없으면 최종 답변으로 확정하지 말고 검색 결과를 반영한 답변을 다시 작성한다.
